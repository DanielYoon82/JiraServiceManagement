<h1>Jira Service Management | IT Help Desk Ticket Lifecycle Lab</h1>

<h3>Project Overview</h3>
This home lab demonstrates the complete IT support ticket lifecycle using Jira Service Management. The project simulates real-world Help Desk operations by managing incidents and service requests from initial ticket creation through investigation, troubleshooting, documentation, resolution, user communication, and ticket closure.<br />

- Demonstrate the complete IT support ticket lifecycle
- Practice documenting troubleshooting activities in Jira Service Management
- Simulate professional communication with end users
- Perform incident management and service request fulfillment

<h3>Issue </h3>
A user reports being unable to print documents due to a suspected network printer connectivity issue.
</p>  
<br />

<h3>Actions Performed </h3>


- Reviewed the support request submitted through Jira Service Management
- Updated the ticket status to In Progress
- Documented troubleshooting activities using internal notes

- Changed the ticket status to Resolved

<h3>Ticket Lifecycle Demonstrated </h3>

1. User submits a request
2. Ticket is reviewed and prioritized
3. Ticket status changes to In Progress
4. Technical investigation begins
5. Troubleshooting actions are performed
6. Internal documentation is recorded
7. User is updated throughout the process
8. Issue is resolved
9. Resolution is verified
10. Ticket is closed
